# JuraKek Park

Client zum Mitspielen. Der Quellcode liegt nicht in diesem Repo.

## Starten

1. Oben auf **Code → Download ZIP** klicken und das ZIP irgendwohin entpacken, wo du schreiben darfst, zum Beispiel auf den Desktop.
2. `JuraKekPark.exe` starten. Warnt Windows SmartScreen, klicke auf „Weitere Informationen“ und dann auf „Trotzdem ausführen“: Die EXE ist nicht signiert.
3. Beim ersten Start erzeugt das Spiel seine 3D-Modelle selbst. Das dauert ein paar Minuten.

Voraussetzungen: Windows 10 oder 11 (64 Bit) und eine Grafikkarte mit DirectX 12.

## Updates

Das Spiel prüft vor dem Hauptmenü, ob es hier eine neue Version gibt, lädt nur die geänderten Dateien und startet neu. Ohne Internet startet es einfach mit der vorhandenen Version. Mit `--no-update` wird die Prüfung übersprungen.

Mehr steht in `Mitspielen.txt`.
